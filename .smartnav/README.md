# ⚠ `.smartnav/` 是研究數據，不是暫存檔——請勿刪除

這個目錄看起來像 runtime 產生的快取，**但它不是**。
裡面每一個檔案都是實機跑出來的量測資料，**專題總報告要引用**。

## 內容與用途

| 路徑 | 是什麼 | 為什麼不能刪 |
|---|---|---|
| `path_database/paths.json` | 教導－重現的路徑資料庫（7,000+ 行） | E8 循跡精度實驗的原始素材。報告第四章的循跡誤差 0.175 m 就是從這批路徑重播出來的 |
| `waypoint_database/waypoints.json` | 導航目標點（含 7/31 備份） | 迎賓故事線的「帶位到哪裡」定義；重錄要重跑整套流程 |
| `map_database/` | SLAM 建出來的地圖（`.pgm` + `.yaml`） | 建圖要實機跑一趟才有。刪掉＝那趟實驗白做 |
| `nav_state.json` | 目前使用中的地圖 | 開機要讀 |
| `steering_trim.json` | 舵機補償值 | 8/29 實機標定的結果 |
| `face_database/` | 人臉特徵向量 | ⚠ **含個資，不進版控**（已 gitignore） |
| `secrets/` | Telegram token 等 | ⚠ **絕不進版控**（已 gitignore） |
| `visit_log.db` | 到訪紀錄 | 報告的到訪統計章節 |

## 如果你正在整理這個 repo

**要刪之前請先問一聲。** 這些檔案「沒有被程式碼 import」是正常的——
它們是**資料**不是程式碼，靠 runtime 的路徑字串讀取，靜態分析看不出有人用。

判斷準則很簡單：**能不能用重跑一次指令生出來？**
- 可以 → 是快取，刪無妨（例如 `build/`、`install/`、`log/`、`__pycache__/`）
- 不行，要把車子推出去跑一趟才有 → 是研究數據，**不可刪**

`.smartnav/` 全部屬於後者。

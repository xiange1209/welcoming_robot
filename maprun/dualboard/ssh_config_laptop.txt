# 貼到筆電的 %USERPROFILE%\.ssh\config（沒有這個檔就新建，用記事本存成 UTF-8、不要副檔名）。
# 之後在命令提示字元打 ssh car-a 或 ssh car-b 就能連；VS Code Remote-SSH 也吃這份設定。
# car-b 透過 car-a 跳板（B 只接網路線、不接 Wi-Fi）。
# ★ car-a 的 IP 是筆電熱點用 DHCP 給的（10/20～10/22 是 192.168.137.106），變了就改 HostName。
# ★ 正式運作時不要用 VS Code 連 B：10/22 在 4 GB 板上量到 VS Code 伺服器＋Claude 吃掉約 2.2 GB 記憶體，
#   B 要留給人臉與語音（ssh 連進去看 log 沒關係）。

Host car-a
    HostName 192.168.137.106
    User user

Host car-b
    HostName 10.10.10.2
    User user
    ProxyJump car-a

邊緣裝置（筆電）

節點歸屬是比對本機行程判定的：在這台 Pi 找得到對應行程就歸左欄， 其餘視為在另一台機器上。判定不準的節點可用 pi_nodes / edge_nodes 參數釘死。
顯示「未就緒」代表對應節點沒啟動，不是網頁壞掉——地圖與導航需要 map_service_node、waypoint_service_node 與 nav2； 使用者管理需要 user_auth_node，照片註冊另外需要 face_embedding_node。

語音測試（跳過 LLM 直接播報）

兩條路不一樣，按下去沒反應多半是按到第二條：
①「用這台裝置播報」——走瀏覽器內建的 speechSynthesis， 也就是「迎賓」頁那顆朗讀鈕用的同一套。車上沒有喇叭 （唯一的音訊裝置是 Astra S 的麥克風，只能錄不能放），所以聲音是從 你手上這台平板出來的。這條現在就能用。
②「走 ROS 語音鏈」——發到 speech_text 話題，需要 speech_synthesizer_node 在跑、而且 sherpa-onnx 的 TTS 模型已下載。 2026-08-10 現況：兩者都還沒有，所以這條按了不會有聲音，這是預期行為。

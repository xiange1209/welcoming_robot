# sherpa-onnx 熱詞（contextual biasing）— 銀行迎賓場景
#
# 2026-08-14 建立。使用者回報「辨識錯誤」，而中文 ASR 的錯幾乎都是同音字
# （開護/開戶、帶款/貸款、題款/提款）。熱詞在解碼時對清單裡的詞加分，
# 讓同音候選裡的正確那個勝出。
#
# ★ 格式：一行一個詞，**字與字之間要空一格**（char-based 中文模型的 token
#   就是單字）。詞尾可加 `:分數` 覆寫個別權重，例如 `貴 賓 室 :2.5`。
# ★ 只在 decoding_method = modified_beam_search 時生效（本節點已設）。
# ★ 以 # 開頭的行與空行會被 sherpa-onnx 忽略。
#
# ⚠ 不要無限加詞。熱詞是把機率往這些詞拉，清單越長、拉扯越雜，
#   反而會把不相干的句子扭曲成銀行詞彙。只放**這個展示會真的出現**的詞。
#   加詞之後一定要重測那 10 句標準測試語句，確認沒有把原本對的弄錯。
